# Skill: refactorización

- Solo con pruebas que cubran el comportamiento actual; si no las hay, escribirlas primero.
- Un objetivo por refactor (renombrar, extraer, mover). No mezclar con cambios funcionales.
- Mantener las firmas públicas de la API o versionarlas.
- Antes de extraer una utilidad, buscar si ya existe una equivalente.
- Registrar en change-log como tipo `refactor`.
