# Skill: actualización de documentación

Después de cada cambio, revisar qué documento quedó desactualizado:

| Si cambió... | Actualizar |
|---|---|
| Qué se está haciendo | `context/Trabajo-Activo.md` (siempre) |
| Carpetas, módulos o archivos clave | `context/Modulo-Map.md`, `chunks/module-index.md` |
| Una decisión técnica | nuevo ADR + `context/Decisiones-Actuales.md` |
| Una regla de negocio | `docs/analisis-funcional-mvp.md` |
| Cómo instalar o desplegar | `README.md`, `docs/` |
| Un riesgo nuevo o mitigado | `context/Riesgos-Conocidos.md` |

Escribir corto: viñetas, sin repetir lo que ya está en otro archivo (enlazar).
