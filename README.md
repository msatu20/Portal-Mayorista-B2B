# Portal Mayorista B2B

Portal web de venta de celulares para clientes revendedores. El catálogo y los precios de costo
se toman de la lista del proveedor (CSV); el portal publica mis propios precios y recibe pedidos
para retirar, verificando antes la disponibilidad con el proveedor.

- Estado: **análisis y marco de IA** (todavía sin código de aplicación).
- Análisis funcional del MVP: [docs/analisis-funcional-mvp.md](docs/analisis-funcional-mvp.md)
- Marco de trabajo para IAs: [.ai/README.md](.ai/README.md)

Stack previsto: Next.js + NestJS + Prisma + PostgreSQL (TypeScript de punta a punta).
