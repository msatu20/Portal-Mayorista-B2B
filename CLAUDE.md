# Instrucciones para Claude Code

Este repositorio usa un marco de trabajo para agentes de IA en `.ai/`.

Antes de cualquier tarea:
1. Leé `.ai/agents/orchestrator.md` (flujo obligatorio).
2. Leé `.ai/context/Trabajo-Activo.md` y `.ai/context/Modulo-Map.md`.
3. Cargá solo los agentes, skills y contextos que la tarea necesite (ver `.ai/chunks/README.md`).

Después de cada cambio: registrar en `.ai/change-log/` y actualizar el contexto afectado.
Idioma: español rioplatense en documentación, commits y textos de la interfaz. Código (identificadores) en inglés.
